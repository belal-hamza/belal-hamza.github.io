# بورتفوليو بلال — تحويل الرابط القديم فقط

**التعديل على الموقع من [المشروع الأساسي belal-portfolio](https://github.com/belal-hamza/belal-portfolio).**

هذا المستودع يحوّل زوار رابط GitHub Pages القديم إلى رابط Firebase الجديد.
النصوص والصور والتصميم محفوظة في المشروع الأساسي الخاص؛ يلزم تسجيل الدخول بحساب المالك لفتحه.

[افتح الموقع](https://belalhamza.web.app/)

تعديلات الموقع تُنشر تلقائيًا إلى Firebase بعد نجاح فحص الفرع `main` في المشروع الأساسي.
لتحديث صفحة التحويل فقط: شغّل `pnpm run deploy:redirect` من المشروع الأساسي.
أصل النسخة المنشورة مسجّل في `version.json`. لا تعدّل الملفات المولّدة هنا يدويًا.
